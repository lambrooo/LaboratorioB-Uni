# Immagini per la Documentazione

Questa directory contiene le immagini utilizzate nella documentazione del progetto Book Recommender.

## Elenco delle immagini richieste

1. `schermata_principale.png` - Schermata principale dell'applicazione
2. `avvio_server.png` - Finestra di avvio del server
3. `server_in_esecuzione.png` - Server in esecuzione
4. `avvio_client.png` - Avvio del client
5. `registrazione.png` - Schermata di registrazione
6. `login.png` - Schermata di login
7. `ricerca_titolo.png` - Ricerca per titolo
8. `ricerca_autore.png` - Ricerca per autore
9. `risultati_ricerca.png` - Risultati della ricerca
10. `crea_bookshelf.png` - Creazione nuova libreria
11. `gestione_bookshelf.png` - Gestione librerie
12. `valutazione_libro.png` - Valutazione libro
13. `suggerimenti.png` - Suggerimenti libro

## Istruzioni

Per completare la documentazione:
1. Catturare screenshot dell'applicazione in esecuzione per ogni funzionalità descritta
2. Rinominare gli screenshot con i nomi indicati sopra
3. Copiare i file in questa directory
4. Verificare che i riferimenti nel manuale utente puntino ai file corretti

I riferimenti nel manuale utente sono nel formato:
```markdown
![Descrizione](immagini_documentazione/nome_file.png)
```
